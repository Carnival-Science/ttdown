## What it is for

Version B (the engine with the new timing model, and any later candidate) is evaluated against Version A on **identical recordings, settings and hardware**, using paired per-track differences. When rights-cleared annotated recordings exist, both are run on the same development set, and once on the held-out set. Without Version A frozen, an improvement can only be asserted, not measured.

## Rules

1. **Version A's algorithm is not modified.** Fixes go into the working `index.html`; the tag is never moved.
2. Each Version B change is reported as its own paired comparison against these stored predictions.
3. Synthetic numbers below are regression evidence, not accuracy claims.

## Reproduce

```bash
npm run songs                                        # or: python3 test-songs/make_test_songs.py
git show analyzer-baseline-a:index.html > versionA.bak.html   # gitignored; --page must be inside the repo
node bench/run.js test-songs/manifest.json --page versionA.bak.html --out /tmp/vA
node bench/score.js /tmp/vA/predictions.json
```

Verified 2026-11-17: re-running the frozen page produced predictions identical to the stored ones for all 8 tracks, ignoring runtime and date fields.
